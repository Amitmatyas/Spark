## על הפרויקט

זה דף הנחיתה של SPARK, יחד עם הדפים המשפטיים שלו. האתר סטטי לגמרי: HTML, CSS ו-JavaScript, בלי שלב build ובלי חבילות להתקנה.

המערכת של הסטודיו (שרת, ממשק ניהול, אזור אישי ללקוחות, וואטסאפ ועוזר AI) רצה על ה-NAS ולא נמצאת כאן. טופס הפנייה בדף שולח את הפניות לשם.

## דפים

| דף | קובץ |
|---|---|
| דף הבית | `public/index.html` |
| מדיניות פרטיות | `public/privacy.html` |
| תנאי שימוש | `public/terms.html` |
| הצהרת נגישות | `public/accessibility.html` |
| עמוד שגיאה | `public/404.html` |

## מבנה התיקיות

| נתיב | מה יש בו |
|---|---|
| `public/` | כל מה שמתפרסם באתר |
| `public/assets/` | עיצוב, סקריפטים, פונט, לוגו ואייקונים |
| `public/media/` | סרטון הפרומו ותמונת השיתוף |
| `vercel.json` | הגדרות הפריסה ל-Vercel |
| `.gitignore` | רשימת הקבצים שמותר להעלות |

## הרצה מקומית

```bash
npx serve public
```

ואז לפתוח את הכתובת שמופיעה בטרמינל. לא לפתוח את קבצי ה-HTML ישירות מהתיקייה, כי הקישורים בדפים המשפטיים לא יעבדו.

## פריסה

האתר עולה ל-Vercel מתוך התיקייה `public`.

בזמן הפריסה Vercel מחליף את `__SITE_URL__` בכתובת האתר, בדף הבית, ב-sitemap וב-robots. בקוד עצמו משאירים את `__SITE_URL__` כמו שהוא.

## לפני שמוסיפים קובץ

ה-`.gitignore` חוסם כל קובץ שלא מופיע בו במפורש. קובץ חדש ב-`public` לא ייכנס ל-git עד שמוסיפים לו שורה עם `!` בתחילתה.

## שינוי כתובת השרת

כתובת השרת שהטופס שולח אליו מוגדרת במשתנה `API_BASE`, בשני מקומות:

- `public/index.html`
- `public/assets/legal.js`

אם השרת עובר כתובת, צריך לעדכן את שניהם.
